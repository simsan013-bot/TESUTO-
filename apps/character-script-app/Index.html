AUDIO SCRIPT GENERATOR

🎤 キャラ別台本生成App

スプレッドシートの台本データを音声モデル別 Google Doc に自動変換します

⚙ SETTINGS 実行設定
スプレッドシートURLの d/ と /edit の間 にある長い英数字文字列です
1
初回・シナリオ更新時　まずキャラ一覧を書き出してから voice_id などを入力してください。
書き出し先：スプシ内「キャラ一覧」タブ（タブ2として使用）
2
「キャラ一覧」タブに voice_id を入力済みの場合
モデル別 Doc を生成します。タブ2（モデル指定）が必要です。
📋 LOG 処理ログ
⏸ 待機中
ここに処理ログが表示されます
📖 GUIDE スプレッドシートの構成
タブ1：台本
A列：【キャラ名】　または　===状況説明===　または　===SPLIT=== B列：セリフテキスト（===系の行はB列空欄）
タブ2：モデル指定（「キャラ一覧」タブを使用）
A列：タグ　　B列：【キャラ名】　　C列：voice_id　　D列：speed　　E列：emotion_tag ※ 「キャラ一覧を書き出す」でB列のキャラ名が自動入力されます → C列に voice_id を貼り付けて Doc 生成を実行してください
⚠ 事前準備： スクリプトプロパティに SECRET_KEY を設定してください。
初回デプロイ後は authDrive() を一度実行してスコープを認証してください。
生成された Doc はスプレッドシートと同じフォルダ内の「音声台本」フォルダに保存されます。
